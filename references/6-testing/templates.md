## 准出检查清单：测试 → 验收

主流程校验通过才能进入阶段 7（验收），不达标把缺口清单发回同一个测试 agent 返工。

- 测试报告由测试 agent（独立子 agent）产出，不是主流程代写
- **测试 agent 全程没有读源码、没有构建、没有跑单元测试**（它拿到的只有 debug 包和 PRD）
- 报告里登记了测试对象的**包路径、版本号、安装与启动命令**，与开发 agent 交付的一致
- 关键路径都有真实执行证据
- **PRD 覆盖对照表已填全**：功能清单、业务流程分支、边界与异常、权限与可见性、监测指标、可测的非功能项都有结论或未覆盖原因
- 执行结果标明每条用例覆盖的需求编号
- PRD 的监测日志已逐条校验并留证据
- 关键页面和状态的截图已按页面归档到截图库；无界面需求写明了替代验证方式
- 测试开始后的代码改动已在「变更后补充测试」留证据，且测的是**新包**不是旧包
- 缺陷要么已修复（由开发 agent 修、经评审复审、由开发 agent 重新出包、再由测试 agent 复测新包），要么已记录并说明处理计划
- 范围外的缺陷只记录，已列进「范围外发现」，没有顺手改动
- 未覆盖项写明原因，没有含糊带过
- 测试 agent 未自行改代码、未自行构建；缺陷都是退回开发 agent 处理的
- S 级无界面合并验收时，报告里有「验收结论」一节，逐条对应 AC 编号并附证据
