# 编排模板与检查清单

主流程用这里的模板起 agent、记编排过程。它不是阶段产物，是编排的施工单。

## 任务包模板

```text
<角色名>｜<需求标识>

【身份】你是 <角色名>，相当于 <同事工程师 / 产品经理 / QA / 设计师 …>。先读 <角色卡路径> 再动手。

【任务】
  产出：<这一阶段要产出的文件名>
  做法：<该阶段 README 路径>
  准出清单：<该阶段 templates.md 路径>
  写到：docs/requirements/<需求标识>/<文件名>

【输入】只读下面这些，不要扩散：
  - <上游产物 1 路径>
  - <上游产物 2 路径>
  - <相关源码目录 / 文件清单>
  - 项目规范：<AGENTS.md 路径>

【硬约束】
  - <角色卡的“不做什么”，逐条抄>
  - 只写本阶段产物，不改上游文档
  - 不做不可逆动作（commit / push / 发布 / 删除数据 / 对外发消息）
  - 拿不准写进「待决策」，不要自己拍板
  - 不要参考主流程的判断和自评

【回执】结束后用 send_message 按下面的格式回
```

### 各角色的「不做什么」速查

| 角色 | 必须写进任务包的禁止项 |
| --- | --- |
| 需求 agent | 不写代码、不设计界面、不定技术方案（S 级兼技术方案的除外） |
| 设计 agent | 不写代码、不定接口、不改 PRD；默认不动用计费 MCP 工具 |
| 方案 agent | 不写代码、不改 PRD 的需求内容 |
| 开发 agent | 不自我评审、不下最终测试结论（UI/集成/实跑归测试 agent）、不 commit、不做验收判断 |
| 评审 agent | 不跑构建、不跑测试、不写代码、不判断需求是否达成 |
| 测试 agent | 不看源码、不构建、不跑单元测试；不改代码、不判需求是否达成；缺陷退回开发 agent |
| 验收 agent | 不看源码、不看改动范围、不构建、不评价代码风格 |
| 复盘 agent | 不改任何已有产物 |

## 回执模板

```text
【回执】<角色名>｜<需求标识>
状态：完成 / 部分完成 / 阻塞
产物：<文件路径列表>
自验：<跑了什么、结果如何；未跑写“未验证”+原因>
待决策：<需要拍板的点，没有写“无”>
阻塞与上游问题：<上游缺什么/错什么，没有写“无”>
```

## 校验记录模板

每个阶段结束，在 `编排记录.md` 里追加：

```markdown
### 阶段 N：<阶段名>（<角色名>）
- 实例：<description>
- 回执状态：完成 / 部分完成 / 阻塞
- 产物核对：<逐个文件确认存在、非空壳>
- 准出校验：
  | 准出项 | 结论 | 证据 |
  | --- | --- | --- |
- 返工：<次数与缺口清单，没有写“无”>
- 结论：通过 / 返工 / 阻塞
```

## 编排自查清单（每阶段结束过一遍）

- 该阶段是由独立 agent 产出的，不是主流程自己写的
- 任务包里的输入只有路径和材料，没有主流程的结论和自评
- 该起独立实例的没被合并（开发 / 评审 / 测试；有界面时的验收）
- 该续跑的没被重起（同角色第二次发言一律 `send_message`，复审不是新评审）
- 产物文件真实存在，不是空壳或只有标题
- 准出清单逐项有结论，缺项已返工
- 返工是发回同一个 agent，不是主流程补写
- 需要用户拍板的点已汇总，没有替用户决定
- commit / push 已停下确认，且提交信息原文已展示

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 主流程顺手把缺口补了 | 回到“自己写自己验”，独立性失效 | 返工同一 agent，连续三次不达标就停 |
| 把“已完成”写进下游任务包 | 下游顺着主流程结论走，评审形同虚设 | 只给路径与编号 |
| 同一个实例兼开发和评审 | 自评失真 | 两个实例，重新起 |
| 复审时新起一个评审 agent | 新实例没有首次评审的上下文，把复审当首次评审重做，问题清单越审越多，阶段 5 永远走不到"只剩建议项" | `send_message` 续跑 5a 那个实例，只让它回答本轮编号是否闭环 |
| 每到一个环节就起一个新 agent | agent 数暴涨、上下文断裂（同一个活儿有人不知道前情） | 起多少看角色数不看环节数；同角色续跑一律 `send_message` |
| 用 `subagent_fork` 起执行 agent | 继承主流程推演，独立性没了 | 一律 `subagent` |
| 验收 agent 拿到源码 | 视角退化成代码评审 | 只给 app 和 PRD 验收标准 |
| 只在对话里给结论不落文件 | 下游读不到，等于没做 | 每阶段产物必须落盘 |
